# 便携式储能单元

便携式储能单元（PSU）用于在你的物品栏中转存能量。右击任意储能单元即可进行充电和放电。

<Recipe id="modern_industrialization:electric_age/battery/portable_storage_unit_asbl" />

默认情况下，它不具备能量存储容量。若要增加容量，你需要向其中填充电池——可通过选取电池右击PSU，或选取PSU右击电池来实现。电池等级越高，为储能单元增加的容量就越大。你可以通过右击空槽位取出电池，但电池中超出单元容量的剩余能量将会丢失。
