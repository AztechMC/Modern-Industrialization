# 现代工业化
欢迎来到**现代工业化**!

![管道、管道，更多管道](assets/pipes_pipes_pipes.png)

## 序言
现代工业化是一个关于自动化的模组！这意味着，在某个阶段，任何资源都可以（并且应该）实现自动化生产。

模组进度分为**蒸汽时代**（游戏前期）和其他剩余阶段。在蒸汽时代，你将创建第一批工厂，为后续阶段生产所需资源。这一阶段的挑战主要来自资源管理和生产流程的时间优化。

请注意，大多数蒸汽时代的设备都会在进入下一阶段后过时，因此不必在它们上面投入过多精力。

游戏进程的第二部分是**电气时代**。在这个阶段，强烈建议你自动化每一条产线。

这一阶段建造的设施预计会长久存在，因为它们可以持续升级。电力机器的超频系统意味着你的生产会自动适应消耗需求。

挑战将来自于建立高效且平衡的产线，并优先处理最有用的部分。

电力机器的威力只有在持续运行时才能完全发挥。因此，强烈不建议将现代工业化与按需自动化模组（例如AE2或精致存储）同时使用，因为那会让你的进度变得极其缓慢且低效。
